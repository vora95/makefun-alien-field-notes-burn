A small program that writes one short text (114 characters) to `/output/entry.txt`: a review of planet Earth left by an alien tourist — three stars, lovely planet, but the locals applaud every time the metal tube lands without falling out of the sky.

## Run it

```sh
python3 main.py
```

The entry is written to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`). Standard library only; the output is byte-identical on every run.
